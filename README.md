# RISC-V Processor in Verilog

Designed and implemented a 32-bit RISC-V processor in Verilog HDL supporting core instruction execution, register file operations, ALU functionality, program counter management, and memory access. The processor was verified through simulation and test programs to validate instruction decoding, execution, branching, and data-path operations.

## Features

* RV32I instruction support
* ALU for arithmetic and logical operations
* Register File implementation
* Program Counter and Instruction Fetch
* Control Unit and Instruction Decoder
* Branch and Jump support
* Data Memory and Instruction Memory
* RTL simulation and verification

## Tools Used

* Verilog HDL
* Simulation Environment(Modelsim)
